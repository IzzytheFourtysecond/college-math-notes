\hTwo Here's one more pair of results to justify why we will care about meromorphic functions a lot once we define them in a second.\retTwo

\exTwo\ul{Maximum Modulus Theorem:} Suppose $M$ is a connected Riemann surface and\\ $F: M \to \mathbb{C}$ is a holomorphic function. If $|F|$ attains a local maximum on $M$ then $F$\\ is a constant function.
\begin{myIndent}\exThreeP
	Proof:\\
	Suppose $|F|$ has a local maximum at $p \in M$. Then let $(U, \varphi)$ be a complex chart containing $p$. By shrinking $U$ if necessary, we can also without loss of generality assume $\varphi(U)$ is a connected set. But now  $F \circ \varphi^{-1}$ is a holomorphic function on the region $\varphi(U)$ of $\mathbb{C}$ which also satisfies that $|F \circ \varphi^{-1}|$ attains a local maximum at $\varphi(p)$. It follows by the maximum modulus principle from complex analysis (see \inLinkRap{placeholder}{page 384}) that $F \circ \varphi^{-1}$ is a constant function on $\varphi(U)$. In turn $F \circ \varphi^{-1} \circ \varphi = F$ is also a constant function on $U$. And by the identity principle, we can then conclude that $F$ is constant on $M$. $\blacksquare$\retTwo

	\begin{myIndent}\myComment
		As a side note since I realize that I never showed this, any constant function between Riemann surfaces is automatically holomorphic. To see why, suppose $M$ and $N$ are Riemann surfaces, and $F: M \to N$ satisfies that $F(p) = q \in N$ for all $p \in M$. Then having picked a complex chart $(V, \psi)$ in $N$ containing $Q$, we have for every complex chart $(U, \varphi)$ in $M$ that $F(U) \subseteq V$ and $\psi \circ F \circ \varphi^{-1}$ is a constant function from $\varphi(U) \subseteq \mathbb{C}$ into $\mathbb{C}$. So, $\psi \circ F \circ \varphi^{-1}$ is trivially holomorphic.\retTwo
	\end{myIndent}
\end{myIndent}

\ul{Corollary:} If $M$ is a compact Riemann surface then $O(M, \mathbb{C})$ consists entirely of locally constant functions. In particular, if $M$ is connected then $O(M, \mathbb{C})$ consists only of constant functions. 
\begin{myIndent}\exThreeP
	Proof:\\
	Note that every connected component of $M$ is closed. And since closed subsets of compact sets are compact, we can thus conclude that every connected component of $M$ is compact.\retTwo
	
	Also note that since $M$ is locally connected, we know that every connected component of $M$ is open. Therefore every connected component of $M$ (equipped with the subspace topology) can sill still be viewed as a Riemann surface where $F$ restricted to each\\ component is holomorphic.\retTwo

	Finally, suppose $F \in O(M, \mathbb{C})$ and let $N$ be any connected component of $M$. Then $F$ being continuous on $N$ plus $N$ being compact implies that $|F|$ attains a local maximum on $N$. Yet also note that $F$ being holomorphic on $N$ as a Riemann surface means that the maximum modulus theorem applies. So, we must have that $F$ is constant on $N$. $\blacksquare$.\retTwo
\end{myIndent}

\hTwo Since a lot of the Riemann surfaces we actually care about are compact and connected, we thus can see that $O(M, \mathbb{C})$ is often not the collection of functions we want to study on a Riemann surface. Hence, we will instead often consider $O(M, \mathbb{C}_\infty)$.

\begin{myIndent}\mySepThree\end{myIndent}

To motivate the next bit, observe that if $U \subseteq \mathbb{C}$ is an open set then any meromorphic function $f: U \to \mathbb{C}$ extends to a holomorphic function from $U$ into $\mathbb{C}_\infty$ (in the Riemann surface sense).\newpage
\begin{myIndent}\pracTwo
	If you squint you can see that this is just my comment from \inLinkRap{placeholder}{page 467}. After all, $z \mapsto f(z)$ is a holomorphic function from $U - f^{-1}(\{\infty\})$ into $\mathbb{C}$ and $z \mapsto 1/f(z)$ is a holomorphic function from $U - f^{-1}(\{0\})$ into $\mathbb{C}$.\retTwo
\end{myIndent}

Conversely, suppose $G \subseteq \mathbb{C}$ is a region and $f: G \to \mathbb{C}_\infty$ is a holomorphic function (in the Riemann surface sense) satisfying that there exists $z \in G$  with $f(z) \neq \infty$. Since $f$ is not the constant $\infty$-valued function, we know by the identity principle that $f^{-1}(\{\infty\})$ can't have any limit points. This also means every $a \in f^{-1}(\{\infty\})$ must be an isolated point of $G$.\retTwo

Let $\Omega \coloneqq G - f^{-1}(\{\infty\})$. Since $f$ is continuous, we can conclude that $\Omega$ is an open subset of $G$. So, we consider the chart $(\Omega, \myId_{\Omega})$. Next, we consider the chart $(\mathbb{C}, \myId_\mathbb{C})$ in the standard structure on $\mathbb{C}_\infty$. So, $\myId_{\mathbb{C}} \circ f \circ \myId_{\Omega} = f$ is a holomorphic function from $\Omega$ into $\mathbb{C}$ (in the complex analytic sense).\retTwo

But now $f|_\Omega$ has singularities at every $a \in f^{-1}(\{\infty\})$. Also by the continuity of $f$ on $G$, we know that $|f(z)| \to \infty$ as $z \to a$. Therefore, we can conclude that $f|_{\Omega}$ has poles at all $a \in G - \Omega$. Or in other words, $f$ is a meromorphic function on $G$ (in the complex analytic sense).\retTwo

All in all, we can conclude that if $U \subseteq \mathbb{C}$ is an open set, then the set of meromorphic\\ functions on $U$ is precisely equal to $O(U, \mathbb{C}_\infty) - \mathcal{F}$ where $\mathcal{F}$ is the collection of\\ holomorphic functions that are constantly $\infty$ on any neighborhood. For the time\\ being, I'm going to denote the set of meromorphic functions on $U$ as $\mathcalli{M}(U)$.

\exTwo\ul{Proposition:} Let $X$ be a connected Riemann surface. And suppose $f: X \to \mathbb{C}_\infty$ is a function such that $f \not\equiv \infty$ on $X$. Then the following are equivalent.
\begin{itemize}
	\item[(a)] $f: X \to \mathbb{C}_\infty$ is a holomorphic function.
	\item[(b)] For all complex charts $(U, \varphi)$ on $X$ we have that $f \circ \varphi^{-1}$ is a meromorphic function on $\varphi(U)$.
	\item[(c)] For every $p \in X$ there exists a complex chart $(U, \varphi)$ on $X$ with $p \in U$ and $f \circ \varphi^{-1}$ a meromorphic function on $\varphi(U)$.  
\end{itemize}

\begin{myIndent}\exThreeP
	$(a \Longrightarrow b)$\\
	Let $(U, \varphi)$ be any complex chart on $X$. Since $f$ is continuous and $f \not\equiv \infty$ on $X$, we know that $f^{-1}(\{\infty\}) \cap U$ must be a closed set (relative to $U$) with no limit points in $U$. In other words, $\Omega \coloneqq U - f^{-1}(\{\infty\})$ is an open set with $f(\Omega) \subseteq \mathbb{C}_\infty - \{\infty\}$. If we now consider\newpage the charts $(\Omega, \varphi|_\Omega)$ and $(\mathbb{C}, \myId)$, we know that $\myId \circ f \circ \varphi^{-1} = f \circ \varphi^{-1}$ is a holomorphic map from $\varphi(\Omega) = \varphi(U) - \varphi(f^{-1}(\{\infty\}))$ into $\mathbb{C}$ since $f$ is holomorphic in the Riemann surface sense. Furthermore, we know every $a \in \varphi(U - \Omega)$ has a neigborhood $N$ where $f \circ \varphi^{-1}(z) \neq \infty$ for any $z \in N - \{a\}$. Plus by the continuity of $f \circ \varphi^{-1}$, we know that $f \circ \varphi^{-1}(z) \to \infty$ as $z \to a$. So, every $a \in \varphi(U - \Omega)$ is a pole. And this finishes showing that $f \circ \varphi^{-1}$ is meromorphic on $\varphi(U)$.\retTwo

	$(b \Longrightarrow c)$\\
	This is obvious.\retTwo

	$(c \Longrightarrow a)$\\
	Suppose $p \in X$ and let $(U, \varphi)$ be a complex chart on $X$ such that $p \in U$ and $f \circ \varphi^{-1}$\\ a meromorphic function on $\varphi(U)$. If $f(p) \neq \infty$ then by shrinking $U$ and $\varphi(U)$ to a\\ coordinate ball around $p$, we can assume $f \neq \infty$ anywhere on $B$. And now $f(U) \subseteq \mathbb{C}$ and $\myId \circ f \circ \varphi^{-1} = f \circ \varphi^{-1}$ is a holomomorphic function on $\varphi(U)$.\retTwo

	Meanwhile, if $f(p) = \infty$ then we know $\varphi(p)$ is a pole of $f \circ \varphi^{-1}$. So, we can shrink $U$ and $\varphi(U)$ to a coordinate ball so that $f \neq 0$ anywhere on $U$. Next, $f(U) \subseteq \mathbb{C}_\infty - \{0\}$ and $z \mapsto 1/f(\varphi^{-1}(z))$ is a holomorphic function on $\varphi(U)$. $\blacksquare$\retTwo
\end{myIndent}

\hTwo Given a Riemann surface $X$, we say $f: X \to \mathbb{C}_\infty$ is \udefine{meromorphic} if $f \in O(X, \mathbb{C}_\infty)$ and $f \not\equiv \infty$ on any neighborhood in $X$. We denote the set of meromorphic functions on $X$ as $\mathcalli{M}(X)$.\retTwo

\pracOne Example: What are the meromorphic functions on $\mathbb{C}_\infty$?
\begin{myIndent}\pracTwo
	Suppose $f: \mathbb{C}_\infty \to \mathbb{C}_\infty$ is meromorphic. Since $\mathbb{C}_\infty$ is compact, we know that $f$ has only finitely many \udefine{poles} (i.e. points in the set $f^{-1}(\{\infty\})$). So, we can let $p_1, \ldots, p_n$ be the poles of $f$ in $\mathbb{C}$ (repeated according to multiplicity). Then $g(z) \coloneqq f(z)\prod_{i=1}^n (z - p_i)$ is a well-defined entire function on $\mathbb{C}$.\retTwo

	Next, let $g(z) = \sum_{k=0}^\infty c_k z^k$ be the Taylor expansion of $g$ about $0$. Since $g$ is an entire function, we know this power series has an infinite radius of convergence. In turn, we also know $g(\frac{1}{z}) = \sum_{k=0}^\infty c_k z^{-k}$ is absolutely convergent for all $z \in \mathbb{C} - \{0\}$. Yet also note $g(\frac{1}{z}) = f(\frac{1}{z})\prod_{i=1}^n (\frac{1}{z} - p_i)$. And since $f$ is meromorphic, we know that $h(z) \coloneqq f(\frac{1}{z})$ has either a removable singularity or pole at $z = 0$. It follows that $z \mapsto g(\frac{1}{z})$ has a pole or removable singularity at $z = 0$ as well.\retTwo

	Yet now we can conclude there exists $K \in \mathbb{N}$ with $c_k = 0$ for all $k \geq K$. (If not then $z \mapsto g(\frac{1}{z})$ would have an essential singularity.) So, we've proven there exists a polynomial $P(z) \in \mathbb{C}[z]$ with $P(z) = f(z)\prod_{i=1}^n (z - p_i)$. Finally, by rearranging our expression and factoring $P(z)$, we can conclude that there exists $\lambda \in \mathbb{C}$ as well as $a_1, \ldots, a_m \in \mathbb{C}$ such that:

	{\centering $f(z) = \lambda\frac{(z - a_1)\cdots (z - a_m)}{(z - p_1)\cdots(z - p_n)}$ \retTwo\par}

	So, $\mathcalli{M}(\mathbb{C}_\infty) \subseteq \mathbb{C}(z)$ (where $\mathbb{C}(z)$ is the field of rational functions in $\mathbb{C}$). Conversely, it's easy to show every rational function is a holomorphic map from $\mathbb{C}_\infty$ into $\mathbb{C}_\infty$. $\blacksquare$\newpage
\end{myIndent}

Here's another interesting observation that the prior example brought to mind.\retTwo

\ul{Lemma:} Suppose $X$ and $Y$ are connected Riemann surface with $X$ also compact. Then any nonconstant holomorphic function $F \in O(X, Y)$ must be surjective.
\begin{myIndent}\pracTwo
	Proof:\\
	Since $F$ is continuous and $X$ is compact, we know that $F(X)$ must be a compact subset of $Y$. In turn, since $Y$ is Hausdorff we also know that $F(X)$ is a closed subset of $Y$.\\ Meanwhile, since $F$ is a nonconstant holomorphic function and $X$ is connected, we know $F$ is an open map. In turn, as $X$ is open we must have that $F(X)$ is an open subset of\\ $Y$. Finally, we trivially know that $F(X) \neq \emptyset$. So, we can conclude from the connectedness\\ of $Y$ that $F(X) = Y$. $\blacksquare$\retTwo
\end{myIndent}

As a result of this lemma, any nonconstant rational function in $\mathbb{C}(z)$ must define a\\ surjective map from $\mathbb{C}_\infty$ into $\mathbb{C}_\infty$. In particular, this means that every nonconstant\\ meromorphic function on $\mathbb{C}_\infty$ will have both poles and zeros.

To start off, suppose $\mcateg{C}$ is a category. Then a \udefine{presheaf} is just a functor $F: \mcateg{C}^{\mathrm{op}} \to \mcateg{Set}$. If we replace the category $\mcateg{Set}$ with a different category $\mcateg{D}$ (say $A$-$\mcateg{mod}$), we just say our presheaf is \udefine{$\mcateg{D}$-valued}.\retTwo

A morphism between presheaves $F_1$ and $F_2$ is just a natural transformation between the two functors. In the special case that the natural transformation $\eta: F_1 \to F_2$ consists of only injective functions, then we say $F_1$ is a \udefine{subpresheaf} of $F_2$.\retTwo

Given a topological $X$, a relevant category for us to define is the category $\mcateg{Op}(X)$ of\\ nonempty open subsets of $X$. The objects of this category are open subsets, and the\\ morphisms are given by set inclusions. Clearly this is a small category. Using this category,\\ we now define a \udefine{presheaf} $\mathcalli{F}$ \textit{over a topological space} $X$ to be:
\begin{itemize}
	\item An assignment to every nonempty open set $U \subseteq X$ some other set $\mathcalli{F}(U)$,
	\item A collection of homomorphisms $r_{V}^U : \mathcalli{F}(U) \to \mathcalli{F}(V)$ (called \udefine{restriction\\ homomorphisms}) for each pair of nonempty open sets $V \subseteq U \subseteq X$ such that:
	\begin{itemize}
		\item[$\circ$] $r_U^U = \myId_{\mathcalli{F}(U)}$,
		\item[$\circ$] If $W \subseteq V \subseteq U$ then $r_W^U = r_W^V \circ r_V^U$. 
	\end{itemize}
\end{itemize}

\begin{myDindent}\myComment
	As a side note, we call the objects $\mathcalli{F}(U)$ \udefine{sections} of the presheaf $\mathcalli{F}$.\retTwo
\end{myDindent}

The subpresheafs in this case that we care about are when we restrict the domain of $\mathcalli{F}$ to only open sets containing some arbitrary point $x \in X$.\retTwo

Let $\mcateg{D}$ denote either $\mcateg{Set}$, $\mcateg{Ab}$, $\mcateg{CRing}$, or $A$-$\mcateg{mod}$ or $A$-$\mcateg{alg}$ (where $A$ is some unital\\ commutative ring). Then let $\mathcalli{F}$ be a  $\mcateg{D}$-valued presheaf over a topological space $X$.\\ Given any $x \in X$ we define the \udefine{stalk of $\mathcalli{F}$ at $x$} to be the direct limit (i.e. colimit) of\\ $\mathcalli{F}$ restricted to the open sets containing $x$:

$$\mathcalli{F}_x \coloneqq \hspace{-1em}\lim\limits_{\substack{\longrightarrow\\ x \in U \in \Obj(\mcateg{Op}(X))}}\hspace{-2em}\mathcalli{F}(U)$$


Then, an element of $\mathcalli{F}_x$ is called a \udefine{germ}.\newpage
\begin{myIndent}\myComment

\end{myIndent}

\end{enumerate}

Let $\widetilde{\gamma} : [-1, 1] \to U$ be a $C^1$-path such that $\widetilde{\gamma}(0) = q$ and $\widetilde{\gamma}^\prime(0) = \mVecAst{w}$. Then let $\gamma \coloneqq \phi \circ \widetilde{\gamma}$. Clearly $\gamma(0) = p$ and $\gamma([-1, 1])$ is contained in $M$. Also by chain rule we have that:
		
		{\centering$\gamma^\prime(0) = (\Df \phi(q))\widetilde{\gamma}^\prime(0) = (\Df \phi(q))\mVecAst{w} = \mVecAst{v}$.\retTwo\par}
	\end{myIndent}

	Now suppose $f \in C^r(M)$.   we define $\Df_{\mVecAst{v}}|_p f = (f \circ \gamma)^\prime(0)$. I claim this definition is independent of the specific path $\gamma$ chosen. After all:
	\begin{myIndent}\color{VioletRed}
		Suppose $\gamma_1$ and $\gamma_2$ are two distinct $C^1$-paths such that $\gamma_i(0) = p$ and $\gamma_i^\prime(0) = \mVecAst{v}$ for both $i$. Then after extending $f$ to a $C^r$ function on an open set $V \subseteq \mathbb{R}^n$ with $V^\prime = V \cap M$ (which we can do since $f \in C^r(M, \mathbb{R})$), we know that:
		
		{\centering$(f \circ \gamma_1)^\prime(0) = \nabla f(p)\cdot \gamma_1^\prime(0) = \nabla f(p) \cdot \mVecAst{v} = \nabla f(p) \cdot \gamma_2^\prime(0) = (f \circ \gamma_2)^\prime(0)$.\retTwo\par}
	\end{myIndent}

	It's also easy to see that the directional derivative $\Df_{\mVecAst{v}}|_p$ is a derivation at $p$. After all, we can just apply the product rule to the gradiant operator and also note that taking a dot product against a fixed vector $\mVecAst{v}$ defines a linear functional.\retTwo
\end{myIndent}

Now consider the function $\widetilde{T_p M}$ to $T_p M$ given by $(p, \mVecAst{v}) \mapsto \Df_{\mVecAst{v}}|_p$. We can see from the\newpage fact that taking a dot product against a fixed vector $\nabla f(p)$ defines a linear functional that our mapping $(p, \mVecAst{v}) \mapsto \Df_{\mVecAst{v}}|_p$ is actually a linear map between vector spaces.\retTwo

Furthermore, I claim that our linear map is injective. After all, suppose $(p, \mVecAst{v})$ maps\\ to the zero derivation (i.e. the derivation mapping every $C^r$ function to $0$). Then let\\ $(p, u_1), \ldots, (p, u_k)$ be an orthonormal $\mathbb{R}$-basis for the vector space $\widetilde{T_p M}$. We can uniquely\\ express $\mVecAst{v} = c_1 u_1 + \ldots + c_k u_k$ where $c_1, \ldots, c_k \in \mathbb{R}$. And now for any $f \in C^1(M ,\mathbb{R})$ we\\ have that:

{\centering $\Df_{\mVecAst{v}}|_p f = \sum_{j=1}^k c_j \Df_{u_j}|_p f$ \retTwo\par}

To finish off, we can define $f_i \in C^1(M, \mathbb{R})$ by $f_i(x) = x \cdot u_i$ for all $x \in M \subseteq \mathbb{R}^n$. This is a $C^1$ map because it more strongly extends to a smooth map on all of $\mathbb{R}^n$. Furthermore, note that $\nabla f_i(p) = u_i$. So, $\Df_{u_j}|_p f = u_i \cdot u_j$. And this equals $1$ if $i = j$ and $0$ otherwise. So, we can conclude for all $i$ that:

{\centering $0 = \Df_{\mVecAst{v}}|_p f_i = \sum_{j=1}^k c_j \Df_{u_j}|_p f_i = c_i$\retTwo\par}

In other words $\mVecAst{v} = 0u_1 + \ldots + 0u_k = 0$. And with that we've proven that $(p, \mVecAst{v}) \mapsto \Df_{\mVecAst{v}}|_p$ has a trivial kernel.\retTwo

Now to finish off, note that $\widetilde{T_p M}$ is $k$-dimensional. We'll also soon show for a general abstract $C^r$ $k$-dimensional manifold that $T_p M$ is $k$-dimensional. Hence, our injective linear map must also be surjective. And thus, we've proven that our linear map $\widetilde{T_p M}$ to $T_p M$ given by $(p, \mVecAst{v}) \mapsto \Df_{\mVecAst{v}}|_p$ is a bijection.\retTwo

The T.L.D.R. to all of this is that you should think of a tangent plane as being isomorphic to a vector space of directional derivative operators. Also, derivations are a generalization of directional derivatives.\retTwo
