\blect{Math 231A Lecture Notes:}\\

I have a few more notes about harmonic functions to take and then I will move on to talking about the heat equation. To start off, the following is useful for bounding harmonic functions. (Also once again I'll just be assuming $n \geq 2$ always.)\retTwo

\exTwo\ul{Harnack's Inequality:} Suppose $U \subseteq \mathbb{R}^n$ is an open set and $K$ is a connected compact set contained in $U$. Then there exists a constant $C > 0$ such that:

{\centering$\max_{x \in K}(u) \leq C \min_{x \in K}(u)$\\[4pt]\par}

for all harmonic functions $u: U \to \mathbb{R}^n$ with $u \geq 0$ on $U$.
\begin{myIndent}\exThreeP
	\begin{myIndent}\myComment
		Note that $C$ does not depend on the function $u$ at all.\retTwo
	\end{myIndent}

	Proof:\\
	Set $r = \frac{1}{4}d(K, \partial U) \coloneqq \frac{1}{4}\inf\{|x - y| : x \in K, y \in \partial U\}$. Since $K$ and $\partial U$ are disjoint closed sets with $K$ compact, we know $r > 0$.\retTwo

	Now for any $x \in K$ and $y \in \overline{B_r(x)}$ we know by the mean value theorem plus the fact that $u$ is nonnegative that:
	
	{\centering$u(x) = \frac{1}{(2r)^n \alpha(n)}\int_{B_{2r}(x)}u \geq \frac{1}{(2r)^n\alpha(n)}\int_{B_{r}(y)}u = \frac{r^n \alpha(n)}{(2r)^n \alpha(n)}u(y) = \frac{1}{2^n}u(y)$\retTwo\par}

	But now observe that because $K$ is compact, we can cover cover $K$ with a finite number $N$ of balls: $B^{(1)}, \ldots, B^{(N)}$, each with radius $r/2$ and centered at a point in $K$. Next, I claim that because $K$ is connected, we can for any $x, y \in K$ always find $z_1, z_2, \ldots, z_\ell \in K$ (where $\ell \leq 2N - 2$) such that $|x - z_1| \leq r$, $|z_i - z_{i+1}| \leq r$ for all $i$, and $|z_\ell - y| \leq r$. In fact, I'll even prove a slightly more general lemma.\retTwo

	\ul{Lemma:} Suppose $(X, d)$ is any metric space, $A \subseteq X$ is a connected set, and there exists finitely many sets $E_1, \ldots, E_N$ of diameter at most $r$ covering $A$. Given any $x, y \in A$ we can always find points $z_1, \ldots, z_\ell \in A$ (where $\ell \leq 2N - 2)$ such that $d(x, z_1) \leq r$, $d(z_i, z_{i+1}) \leq r$ for each $i$, and $d(z_\ell, y) \leq r$.
	\begin{myIndent}\exPPP
		Proof:\\
		It suffices to fix $x \in A$. Now to start off, I shall disregard getting an upper bound for $\ell$ and just show that for any $y \in A$ there even exists points $z_1, \ldots, z_\ell \in A$ such that $d(x, z_1) \leq r$, $d(z_i, z_{i+1}) \leq r$ for each $i$, and $d(z_\ell, y) < r$. To do this, I shall let $C \subseteq A$ be the set of all $y \in A$ such that this is possible. Note that $C$ is nonempty because trivially $x \in C$. Also, we can easily verify both $C$ and $A - C$ are open subsets of $A$. Since $A$ is connected, this thus proves that $C = A$.\retTwo

		Now fixing $y \in A$, we've shown that there are $z_1, \ldots, z_{\ell} \in A$ with $d(x, z_1) \leq r$, $d(z_i, z_{i+1}) \leq r$ for each $i$, and $d(z_\ell, y)\leq r$. For ease of notation, I'll let $z_0 \coloneqq x$ and $z_{\ell + 1} \coloneqq y$.\newpage

		If $\ell > 2N - 2$ then we know by the pigeonhole principle that there are integers $0 \leq i_1 < i_2 < i_3 \leq \ell + 1$ with $z_{i_1}, z_{i_2}, z_{i_3}$ all in the same set $E_j$. Then as $E_j$ has diameter at most $r$, we know $d(z_{i_1}, z_{i_3}) \leq r$. So, we can disregard each of the $z_j$ with $i_1 < j < i_3$ to get another collection of points satisfying our lemma. In particular, this collection has at least one less element because we disregarded $z_{i_2}$.\retTwo

		By repeating the prior reasoning finitely many times, we will eventually get that\\ $\ell \leq 2N - 2$.\retTwo
	\end{myIndent}

	Based on the prior lemma, we can now see for any nonnegative harmonic function\\ $u: U \to \mathbb{R}$ and any $x, y \in K$ that:

	{\centering $ u(x) \geq \left(\frac{1}{2^n}\right)^{2N - 1}u(y)$. $\blacksquare$\retTwo\par}
\end{myIndent}

\hTwo I also want to motivate why we'd care about {\color{OliveGreen}Green's functions}.\retTwo

\pracOne\mySepTwo
Firstly, I want to briefly go over how the textbook (see \inLinkRap{Citation 16}{citation 16}) that my 231 class is\\ loosely based on defines what it means for an open set to have a $C^r$ boundary (where $r \geq 1$).\retTwo

Let $U \subseteq \mathbb{R}^n$ be an open set and let $k \geq 1$. Evans (the author of that textbook) says that\\ $U$ has a \udefine{$C^k$ boundary} if for each $x^{(0)} \in \partial U$ there exists $r > 0$ and a $C^k$ function\\ $\gamma: \mathbb{R}^{n-1} \to \mathbb{R}$ such that upon relabeling and reorienting the coordinate axes if necessary, we have that:

{\centering $U \cap B(x^{(0)}, r) = \{x \in B(x^{(0)}, r) : x_n < \gamma(x_1, \ldots, x_{n-1})\}$ \retTwo\par}

\textit{I} claim that this happens if and only if $U$ is the interior of a regular domain $D$ without\\ corners and whose boundary is $\partial U$.
\begin{myIndent}\pracTwo
	$(\Longleftarrow)$\\
	Hopefully it is obvious how this direction is an easy result of the theorem on\\ \inLinkRap{Theorem page 1170}{pages 1170-1171}.\retTwo

	$(\Longrightarrow)$\\
	We know $D = U \cup \partial U$ is a closed subset of $\mathbb{R}^n$. So if it were a submanifold it would be properly embedded. Also it's clear that $U$ is a $C^r$ submanifold of codimension $0$. At the same time, if $p \in \partial U$ and we let $\gamma$ and $B(x^{(0)}, r)$ be as described in the above definition, then we can apply a change of coordinates:

	{\centering $(x_1, \ldots, x_n) \mapsto (x_1, \ldots, x_{n-1}, \gamma(x_1, \ldots, x_{n-1}) - x_n)$ \retTwo\par}

	in order to get an $n$-dimensional half slice chart for $D$ centered at $p$.\retTwo
\end{myIndent}
\mySepTwo

\hTwo Now suppose $U \subseteq \mathbb{R}^n$ is a bounded open set with a $C^1$ boundary. At any point $p \in \partial U$ we let $v(p)$ denote the outward pointing unit normal vector. Also let $\Phi: \mathbb{R}^n - \{0\} \to \mathbb{R}$ be the fundamental solution of $-\triangle$. (See \inLinkRap{Fundamental Solution of $-\triangle$}{page 1181}). And let $\tau_x f(y) \coloneqq f(y - x)$.\newpage

\exTwo\ul{Observation:} Let $u \in C^2(\overline{U})$ be an arbitrary function. Then for any $x \in U$:
$$u(x) = \int_{\partial U} \Phi(y - x)\frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y) - \int_U \Phi(y - x)\triangle u(y)\df y$$
\begin{myIndent}\pracTwo
	Proof:\\
	Fix any $x \in U$ and let $\varepsilon > 0$ be small enough so that $\overline{B_\varepsilon(x)} \subseteq U$. Then let $V_\varepsilon = U - B_\varepsilon$.\retTwo

	We have by {\color{OliveGreen}Green's $2$nd identity} that:

	{\centering\begin{tabular}{l}
		$\int_{V_\varepsilon} \Phi(y - x)\triangle u(y) \df y = \int_{\partial V_\varepsilon} \Phi(y - x) \frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y)$\\ [8pt]
		$\phantom{\int_U \Phi(y - x)\triangle u(y) \df y} = \int_{\partial U} \Phi(y - x) \frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y)$\\ [2pt]
		$\phantom{aaaaaaaaaaaaaaaaaaaaaaaaaaaa} - \int_{\partial B_\varepsilon(x)} \Phi(y-x) \frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y)$
	\end{tabular}\retTwo\par}

	But now $\left|\int_{\partial B_\varepsilon(x)} \Phi(y - x) \frac{\partial u}{\partial v}(y)\df S(y)\right| = \int_{\partial B_\varepsilon(x)} |\Phi(y - x)| \cdot |\nabla u(y)|\df S(y)$. For\\ small enough $\varepsilon$ we can guarentee that there is some $C > 0$ with $|\nabla u(y)| \leq C$ for\\ all $y \in B_\varepsilon(x)$. And thus:

	{\centering $\left|\int_{\partial B_\varepsilon(x)} \Phi(y - x) \frac{\partial u}{\partial v}(y)\df S(y)\right| \leq C\varepsilon^{n-1} n\alpha(n) \max_{y \in \partial B_\varepsilon(0)}|\Phi(y)|$ \retTwo\par}

	If $n = 2$ then $\varepsilon \ln(\varepsilon) \to 0$ as $\varepsilon \to 0$. In other words $\ln(\varepsilon) = o(\varepsilon^{-1})$ as $\varepsilon \to 0$.\\ Similarly, if $n \geq 3$ then $\varepsilon^{2-n} = o(\varepsilon^{1 - n})$ as $\varepsilon \to 0$. So in general, we can conclude:

	{\centering $C\varepsilon^{n-1} n\alpha(n) \max_{y \in \partial B_\varepsilon(0)}|\Phi(y)| = \varepsilon^{n-1}o(1 - n) = o(1)$ as $\varepsilon \to 0$. \retTwo\par}
	
	Meanwhile, note that if $n = 2$ and $y \neq 0$ then $\nabla \Phi(y) \cdot \frac{y}{|y|} = \frac{-1}{2\pi|y|}$. Similarly, if $n \geq 3$ then $\nabla \Phi(y) \cdot \frac{y}{|y|} = \frac{-1}{n\alpha(n)|y|^{n-1}}$. So, we can say that:

	{\center$\int_{\partial B_\varepsilon(x)}  u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y) = \frac{-1}{n\alpha(n)\varepsilon^{n-1}}\int_{\partial B_\varepsilon(x)}u(y)\df S(y) \to -u(x)$ as $\varepsilon \to 0$. \retTwo\par}

	And thus we've proven that by taking $\varepsilon \to 0$, we have that:

	{\centering\begin{tabular}{l}
		$\int_{V_\varepsilon} \Phi(y - x)\triangle u(y) \df y = \int_{\partial V_\varepsilon} \Phi(y - x) \frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y)$\\ [8pt]
		$\phantom{\int_U \Phi(y - x)\triangle u(y) \df y} = \int_{\partial U} \Phi(y - x) \frac{\partial u}{\partial v}(y) - u(y)\frac{\partial (\tau_x\Phi)}{\partial v}(y)\df S(y) - u(x)$. $\blacksquare$
	\end{tabular}\retTwo\par}
\end{myIndent}

\hTwo Based on the prior observation, we can thus say that $u$ is uniquely determined on $U$ by $u$ and $\frac{\partial u}{\partial v}$ on $\partial U$ as well as $\triangle u$ on $U$. That said though, our PDE is actually over-determined if we give boundary conditions for both $u$ and $\frac{\partial u}{\partial v}$ on $\partial U$.\retTwo

We focus on the Dirichlet problem (i.e. where we don't control for $\frac{\partial u}{\partial v}$ at all). So, we need to cancel out the integral $\int_{\partial U} \Phi(y - x)\frac{\partial u}{\partial v}(y)\df S(y)$. To do this, we shall assume there exists a corrector function $\phi: U \times \overline{U} \to \mathbb{R}$ such that:
\begin{itemize}
	\item $\triangle_y \phi(x, y) = 0$ for all $x, y \in U$
	\item $\phi(x, y) = \Phi(y - x)$ for all $x \in U$ and $y \in \partial U$.
	\item $\phi^x(y) \coloneqq \phi(x, y)$ satisfies that $\phi^x \in C^2(\overline{U})$.
\end{itemize}
\begin{myIndent}\myComment
	(Don't worry for now about if $\phi$ exists. It will be our goal later to prove it exists and calculate it in the cases we are interested in.)\newpage
\end{myIndent}

By {\color{OliveGreen}Green's $2$nd identity} we have that:
$$-\int_U \phi^x(y)\triangle u(y) \df y = \int_{\partial U}u(y)\frac{\partial \phi^x}{\partial v}(y) - \Phi(y - x) \frac{\partial u}{\partial v}(y) \df S(y)\text{.}$$

\phantom{.}\\And by combining that with our prior observation we get that:
$$u(x) = \int_{\partial U} u(y)\left[\frac{\partial \phi^x}{\partial v}(y) - \frac{\partial (\tau_x\Phi)}{\partial v}(y)\right]\df S(y) + \int_U \left[\phi^x(y) - \Phi(y - x)\right]\triangle u(y)\df y$$

\phantom{.}\\ Notably the prior expression writes $u$ purely in terms of $u|_{\partial U}$ and $\triangle u$ on $U$.\retTwo

We define {\color{OliveGreen}\udefine{Green's function}}\udefine{ associated to the domain $\overline{U}$} to be the map:

{\centering$G(x, y) \coloneqq \Phi(y - x) - \phi^x(y)$.\retTwo\par}

And by the prior reasoning, we can conclude the following theorem:\retTwo

\exTwo\ul{Theorem:} Suppose $u \in C^2(\overline{U})$ satisfies that $-\triangle u = f$ on $U$ and $u = g$ on $\partial U$ (where\\ $f$ and $g$ are continuous). Then:
$$u(x) = -\int_{\partial U}u(y)\frac{\partial G}{\partial v}(x, y)\df S(y) + \int_U f(y) G(x, y)\df y\text{.}$$
\begin{myIndent}\myComment
	(Here $\frac{\partial G}{\partial v}(x, y) = \nabla_y G(x, y) \cdot v$.)\retTwo
\end{myIndent}

Given an open set $U \subseteq \mathbb{R}^n$ with a $C^1$ boundary, another way we can interpret {\color{OliveGreen}Green's\\ function} associated to $\overline{U}$ is that it is the map satisfying that $-\triangle_y G(x, y) = \delta_x$ for all\\ $x, y \in U$ and $G(x, y) = 0$ for all $x \in U$ and $y \in \partial U$.\retTwo

\exTwo\ul{Theorem:} For all $x, y \in U$ with $x \neq y$ we have that $G(x, y) = G(y, x)$.
\begin{myIndent}\exThreeP
	Proof:\\
	Fix $x, y \in U$ and define $w_1(z) \coloneqq G(x, z)$ and $w_2(z) \coloneqq G(y, z)$. Then $\triangle w_1(z) = 0$ for\\ all $z \in U - \{x\}$, $\triangle w_2(z) = 0$ for all $z \in U - \{y\}$, and $w_1(z) = w_2(z) = 0$ if $z \in \partial U$. Now let $\varepsilon > 0$ be such that $B_{2\varepsilon}(x) \cap B_{2\varepsilon}(y) = \emptyset$ and $B_{2\varepsilon}(x) \cup B_{2\varepsilon}(y) \subseteq U$.\retTwo
	
	By {\color{OliveGreen}Green's 2nd Identity} applied to the domain $V = U - (B_{\varepsilon}(x) \cup B_{\varepsilon}(y))$ we have that:

	{\centering $0 = -\int_{\partial B_\varepsilon(x) \cup \partial B_\varepsilon(y)} w_1 \frac{\partial w_2}{\partial v} - w_2 \frac{\partial w_1}{\partial v}\df S$. \retTwo\par}

	Or after some rearranging, we can equivalently say that:

	{\centering $ \int_{\partial B_\varepsilon(y)}w_1 \frac{\partial w_2}{\partial v}\df S - \int_{\partial B_\varepsilon(y)}  w_2 \frac{\partial w_1}{\partial v}\df S =  \int_{\partial B_\varepsilon(x)} w_2 \frac{\partial w_1}{\partial v}\df S - \int_{\partial B_\varepsilon(x)} w_1 \frac{\partial w_2}{\partial v} \df S$ \retTwo\par}

	But now observe the following:
	\begin{myIndent}\exPPP
		$w_1$ is a smooth function on $B_\varepsilon(y)$ (since it is harmonic on $U - \{x\}$). So, we can find a constant $C > 0$ with $|\nabla w_1| \leq C$ on $\overline{B_\varepsilon(y)}$. And then:

		{\centering $\left|\int_{\partial B_\varepsilon(y)}  w_2 \frac{\partial w_1}{\partial v}\df S\right| \leq C\int_{\partial B_\varepsilon(y)} |w_2|\df S \leq C\varepsilon^{n-1} n\alpha(n) \max\limits_{z \in \partial B_\varepsilon(y)}|w_2(z)|$ \retTwo\par}

		Next, $w_2(z) = \Phi(z - y) - \phi^y(z)$. But $\phi^y$ is a smooth (since it is harmonic) function around $y$. So there exists a constant $D > 0$ with $|\phi^y(z)| \leq D$ for all $z \in \overline{B_\varepsilon(y)}$.\newpage And now:

		{\centering $ C\varepsilon^{n-1} n\alpha(n) \max\limits_{z \in \partial B_\varepsilon(y)}|w_2(z)| \leq CD\varepsilon^{n-1} n \alpha(n) + o(1)$ as $\varepsilon \to 0$ \retTwo\par}

		This finishes proving that $\int_{\partial B_\varepsilon(y)}  w_2 \frac{\partial w_1}{\partial v}\df S \to 0$ as $\varepsilon \to 0$.\retTwo
	\end{myIndent}

	Analogous reasoning as in the prior observation shows that $\int_{\partial B_\varepsilon(x)} w_1 \frac{\partial w_2}{\partial v} \df S \to 0$ as\\ $\varepsilon \to 0$. And so, we can conclude that:

	{\centering $\lim\limits_{\varepsilon \to 0^+}\int_{\partial B_\varepsilon(y)}w_1 \frac{\partial w_2}{\partial v}\df S = \lim\limits_{\varepsilon \to 0^+} \int_{\partial B_\varepsilon(x)} w_2 \frac{\partial w_1}{\partial v}\df S$ \retTwo\par}

	Finally, we just have to compute these two limits.
	\begin{myIndent}\exPPP
		Note that:
		
		{\centering$\int_{\partial B_\varepsilon(y)}w_1 \frac{\partial w_2}{\partial v}\df S = -\frac{1}{n\alpha(n)\varepsilon^{n-1}}\int_{\partial B_\varepsilon(y)}w_1 \df S + \int_{\partial B_\varepsilon(y)} w_1 \frac{\partial \phi^y}{\partial v} \df S$.\retTwo\par}

		As $\varepsilon \to 0$ we have that $-\frac{1}{n\alpha(n)\varepsilon^{n-1}}\int_{\partial B_\varepsilon(y)}w_1 \df S \to -w_1(y)$.\retTwo

		Meanwhile, because $w_1$ and $\phi^y$ are smooth on $\overline{B_\varepsilon(y)}$ (since they are harmonic), we can find a constant $C$ such that $|w_1 \nabla \phi^y| \leq C$ on $\overline{B_\varepsilon(y)}$. And now:

		{\centering $\left|\int_{\partial B_\varepsilon(y)} w_1 \frac{\partial \phi^y}{\partial v} \df S\right|  \leq C\varepsilon^{n-1}\alpha(n) n \to 0$ as $\varepsilon \to 0$.
		\retTwo\par}

		This finishes showing that $\lim\limits_{\varepsilon \to 0^+}\int_{\partial B_\varepsilon(y)}w_1 \frac{\partial w_2}{\partial v}\df S = -w_1(y)$.\retTwo

		Analogous computations show $\lim\limits_{\varepsilon \to 0^+} \int_{\partial B_\varepsilon(x)} w_2 \frac{\partial w_1}{\partial v}\df S = -w_2(x)$\retTwo
	\end{myIndent}

	So, we've shown that $-G(x, y) = -w_1(y) = -w_2(x) = -G(y, x)$. $\blacksquare$\retTwo
\end{myIndent}

\end{myIndent}

\ul{Proposition:} Suppose $D \subseteq \mathbb{R}^n$ is an embedded $C^1$ submanifold of codimension $0$ with a nonempty boundary. If $f: D^\circ \to \mathbb{R}$ is a $C^1$ map with  $|\nabla f|$ bounded on $D^\circ$, then for all $x \in \partial D$ we have that $\lim_{x^\prime \to x} f(x^\prime)$ exists.
\begin{myIndent}\pracTwo 
	Proof:\\
	Let $(V, \varphi)$ be a smooth chart on $D$ containing $x$. Then let $\widehat{V} = \varphi(V)$ and $\widehat{x} = \varphi(x)$. Note\newpage that $(V, \varphi)$ must be a boundary chart as $x \in \partial D$. Hence, without loss of generality we can assume that $\widehat{x} \in \partial \mathbb{R}_{\geq 0}^n$ and $f \circ \varphi^{-1}$ is defined on $\widehat{V} \cap (\mathbb{R}_{>0}^n)$. Furthermore, because $\varphi$ is a homeomorphism, we know that $\lim_{x^\prime \to x} f(x^\prime)$ exists iff $\lim_{\widehat{x^\prime} \to \widehat{x}} f \circ \varphi^{-1}(\widehat{x^\prime})$ exists. And finally, if we restrict $V$ to the interior of a compact subneighborhood of $x$, we can guarentee that $\|Df \varphi^{-1}\|_{\opnorm}$ is bounded on $\widehat{V}$. In turn, we will get that $|\nabla (f \circ \varphi^{-1})|$ is also bounded on $D^\circ$.\retTwo

	Based on the prior reasoning, it thus suffices to assume $D$ is an open subset of $[0, \infty)^n$\\ and $f \in C^1(D \cap (0, \infty)^n, \mathbb{R})$ with $|\nabla f|$ bounded by some constant. Also, upon\\ writing $x = (x_1, \ldots, x_n)$, we know at least one $x_i$ is zero. By permuting our\\ coordinates if necessary we can always make it so that specifically $x_n = 0$.\retTwo

	Pick $R > 0$ such that $B_R(x) \cap [0, \infty)^n \subseteq D$. Then make the key observation that\\ $B_R(x) \cap (0, \infty)^n$ is convex. As a result, if $|\nabla f(y)| \leq C$ for all $y \in D$, we have that:

	{\centering $|f(y_1) - f(y_2)| \leq C|y_2 - y_1|$ for all $y_1, y_2 \in B_R(x) \cap (0, \infty)^n$. \retTwo\par}

	This lets us conclude that if $\{x_k\}_{k \in \mathbb{N}}$ is \textit{any} sequence in $D$ converging to $x$, then\\ $\{f(x_k)\}_{k \in \mathbb{N}}$ is a Cauchy sequence (and thus converges).
	\begin{myIndent}\exPPP
		Why?\\
		For any $\varepsilon > 0$ there exists $N$ with $|x_m - x_n| < \varepsilon / C$ for all $m, n \geq N$. In turn, $|f(x_m) - f(x_n)| < \varepsilon$ for all $m, n \geq N$.\retTwo
	\end{myIndent}

	Also, if $\{x_k\}_{k \in \mathbb{N}}$ and $\{y_k\}_{k \in \mathbb{N}}$ are differing sequences in $D$ converging to $x$ then $\{f(x_k)\}_{k \in \mathbb{N}}$ and $\{f(y_k)\}_{k \in \mathbb{N}}$ must converge to the same thing.
	\begin{myIndent}\exPPP
		Why?\\
		Suppose to the contrary that they don't and then construct a new sequence by\\ $z_{2k - 1} = x_k$ and $z_{2k} = y_k$ for all $k$. Then $\{f(z_k)\}_{k \in \mathbb{N}}$ will have two distinct\\ subsequential limits (and thus not converge). Yet we also know $\{z_k\}_{k \in \mathbb{N}}$ converges to $x$ in $D$. This contradicts our prior observation. \pracTwo $\blacksquare$
	\end{myIndent}
\end{myIndent}

	This is enough to show by Leibniz's rule that for any $x \in \mathbb{R}^n$, $t > 0$, and $0 < a \leq t$ that $\frac{\partial H}{\partial t}(x, t, a)$ exists and equals $\int_0^a G_t(x, t, s)\df s$.\newpage

	Now, we can apply chain rule to get that if $x \in \mathbb{R}^n$ and $t > 0$ then:

	{\centering\begin{tabular}{l} 
		$u_t(x, t) = \frac{\partial H(x, t, t)}{\partial t} = \int_0^t G_t(x, t, s)\df s + G(x, t, t)$\\ [4pt]
		$\phantom{u_t(x, t) = \frac{\partial H(x, t, t)}{\partial t}} = \int_0^t \int_{\mathbb{R}^n} f_t(x - y, t - s)\Phi(y, s)\df y \df s + \int_{\mathbb{R}^n}f(x - y, 0)\Phi(y, t)$
	\end{tabular}\retTwo\par}

	Meanwhile, because $|G_{x_i}(x, t, s) \leq \|f_{x_i}\|_u$ and $|G_{x_i, x_j}(x, t, s)| \leq \|f_{x_i, x_j}\|_u$ for all:

	{\centering$(x, t, s) \in \{(x, t, s) : x \in \mathbb{R}^n, t > 0, \text{ and } 0 < s < t\}$,\\ [4pt]\par}

	{\centering\begin{tabular}{l}

	$\phantom{u_{x_i, x_i}(x, t) = \frac{\partial^2 H}{\partial x_i^2}(x, t, t)} = \int_0^t \int_{\mathbb{R}^n} f_{x_i, x_i}(x - y, t- s)\Phi(y, s)\df y \df s$.
	\end{tabular}\retTwo\par}

	And with that the hard part is now done because we have successfully moved the derivative operators inside our integral expression and proven that:

	{\centering\begin{tabular}{l}
		$(\partial_t - \triangle)u(x, t)$\\ [2pt]
		$\phantom{aaaaaa} = \int_0^t \int_{\mathbb{R}^n}(\partial_t - \triangle)f(x - y, t - s)\Phi(y, s)\df y \df s + \int_{\mathbb{R}^n}f(x - y, 0)\Phi(y, t)\df y$.
	\end{tabular} \retTwo\par}

	\mySepThree

	\begin{itemize}

		\item $J_\varepsilon \coloneqq \int_0^\varepsilon \int_{\mathbb{R}^n}(\partial_t - \triangle)f(x - y, t - s)\Phi(y, s)\df y \df s$

		{\centering$|J_\varepsilon| \leq \varepsilon \|f_t - \triangle f\|_u \to 0$ as $\varepsilon \to 0$\retTwo\par}
	\end{myIndent}

	\ul{Claim 2:} $I_\varepsilon \to f(x, t) - K$ as $\varepsilon \to 0^+$.

		Why?\\

		{\centering\begin{tabular}{l}
			$\int_\varepsilon^t \int_{\mathbb{R}^n}f_t(x - y, t - s)\Phi(y, s)\df y \df s$\\ [4pt]
			$\phantom{aaaaaaaaaa} = \int_{\mathbb{R}^n} \int_\varepsilon^t f_t(x - y, t - s)\Phi(y, s) \df s \df y$ {\color{red}(by Fubini)}\\ [4pt]
			$\phantom{aaaaaaaaaa} = -\int_{\mathbb{R}^n} \int_\varepsilon^t \frac{\partial f(x - y, t - s)}{\partial s}\Phi(y, s) \df s \df y$\\ [4pt]

			$\phantom{\int_{\mathbb{R}^n} f_{x_i, x_i}(x - y, t - s)\Phi(y, s)\df y} = -\int_{\mathbb{R}^n} \frac{\partial f(x - y, t - s)}{\partial y_i}\Phi_{y_i}(y, s) \df y$\\ [4pt]

			$\phantom{aaaaaaa} = \int_{\mathbb{R}^n} \left[f(x - y, t - \varepsilon) - f(x - y, t)\right]\Phi(y, \varepsilon)\df y + \int_{\mathbb{R}^n} f(x - y, t)\Phi(y, \varepsilon)\df y$

				$\phantom{aaaaaaaaaaaaaaaa} \leq \kappa\int_{\overline{B_\delta(x)}}\Phi(y, \varepsilon)\df y \leq \kappa \int_{\mathbb{R}^n}\Phi(y, \varepsilon) \df y = \kappa$.
			\end{tabular}\retTwo\par}

			{\centering\begin{tabular}{l}
				$\lim\limits_{\varepsilon \to 0^+}\int_{B_\delta(x)^\comp} \left[f(x - y, t - \varepsilon) - f(x - y, t)\right]\Phi(y, \varepsilon)\df y \to 0$ as $\varepsilon \to 0$
			\end{tabular}\retTwo\par}

			Therefore:
			
			{\centering\begin{tabular}{l}
				$\limsup\limits_{\varepsilon \to 0^+}\left|\int_{\mathbb{R}^n} \left[f(x - y, t - \varepsilon) - f(x - y, t)\right]\Phi(y, \varepsilon)\df y\right|$\\ [8pt]
				$\phantom{aaaaaaaaaaaa} = \limsup\limits_{\varepsilon \to 0^+}\left|\int_{\overline{B_\delta(x)}} \left[f(x - y, t - \varepsilon) - f(x - y, t)\right]\Phi(y, \varepsilon)\df y\right| \leq \kappa$
			\end{tabular}\retTwo\par}

			And since $\kappa$ was arbitrary, we can take $\kappa \to 0$ to finish showing this claim.\retTwo
		\end{myIndent}

		Meanwhile, note that $w(x, \varepsilon) \coloneqq \int_{\mathbb{R}^n} f(x - y, t)\Phi(y, \varepsilon)\df y$ is just the solution\\ to the (homogeneous) heat equation $w_t - \triangle w = 0$ with an initial value of\\ $w(x, 0) = f(x, t)$. 		This finishes showing that $I_\varepsilon \to f(x, t) - K$ as $\varepsilon \to 0$.\retTwo
	\end{myIndent}

	And now adding together the limits we just proved finishes showing that:
	
	{\centering$u_t(x, t) - \triangle u(x, t) = f(x, t)$. $\blacksquare$\newpage\par}
\end{myIndent}

Let $G$ be a group (written multiplicatively). We let $m: G \times G \to G$ denote the\\ multiplication map and $i: G \to G$ denote the inverse map. Also let $e$ denote the identity of $G$. A special property of a Lie group $G$ is that the group of smooth diffeo-automorphisms on $G$ acts transitively on $G$. After all, given any $g \in G$ we define $L_g : G \to G$ and $R_g : G \to G$ by:

\exTwo\ul{Lemma:} Suppose $M$ is a compact $n$-dimensional $C^r$ manifold (where $r \geq 1$). Then there exists $N \in \mathbb{N}$ and a $C^r$ embedding $f: M \hookrightarrow \mathbb{R}^N$.
\begin{myIndent}\exThreeP
	Proof:\\
	For every $p \in M$ we can pick a smooth chart $(U_p, \varphi_p)$ such that $p \in U_p$. And then we can pick two more open sets $W_p$ and $V_p$ such that $p \in W_p \subseteq \overline{W_p} \subseteq V_p \subseteq \overline{V_p} \subseteq U_p$. But now as $M$ is compact, we know  there are finitely many $p_1, \ldots, p_\ell$ such that $M \subseteq \bigcup_{i=1}^\ell W_{p_i}$.\retTwo

	For each $i$ let $b_i: M \to [0, 1]$ be a $C^r$ bump function with $b_i \equiv 1$ on $\overline{W_{p_i}}$ and $b_i \equiv 0$\\ on $M - V_{p_i}$. Then by pasting lemma, we can guarentee that the product $b_i \varphi_{p_i}$ defines\\ a $C^r$ map from $M$ to $\mathbb{R}^n$ for each $i$ (where the product equals $0$ at all points outside the\newpage domain of the chart $(U_{p_i}, \varphi_{p_i})$). So, we now define the map $f: M \to \mathbb{R}^{(n + 1)\ell}$ by:

	{\centering $f(p) \coloneqq \left(b_1(p), \ldots, b_\ell(p), (b_1\varphi_1)(p), \ldots, (b_\ell\varphi_\ell)(p)\right)$\retTwo\par}

	Because $M$ is compact, in order to prove that $f$ is a $C^r$ embedding we just need to explain why $f$ is a $C^r$ injective immersion.\retTwo

	Fortunately, because every component function of $f$ is a $C^r$ map, we automatically have that $f$ is a $C^r$ map as well.\retTwo
	
	Also suppose $f(p) = f(q)$. Since $M \subseteq \bigcup_{i=1}^\ell W_{p_i}$ we know that $p \in W_{p_i}$ for some $i$. In turn $b_i(p) = 1$, and since $f(p) = f(q)$ this also guarentees that $b_i(q) = 1$. So, both $p, q$ are covered by the chart $(U_{p_i}, \varphi_{p_i})$ and $\varphi_i(p) = (b_i \varphi_i)(p) = (b_i \varphi_i)(q) = \varphi_i(q)$. Finally, since $\varphi_{p_i}$ is injective on $U_{p_i}$ and $p, q \in U_{p_i}$, we can conclude that $p = q$. So, we have shown that $f$ is injective.\retTwo

	Finally, to prove that $f$ is an immersion, consider any $p \in M$ and then pick $i$ with $p \in W_{p_i}$. Importantly, $b_i \equiv 1$ on a neighborhood of $p$. And now upon identifying:
	
	{\centering$T_{f(p)}\mathbb{R}^{(n + 1)\ell} \cong \left(\bigoplus_{i=1}^\ell T_{b_i(p)}\mathbb{R}\right) \oplus \left(\bigoplus_{i=1}^\ell T_{(b_i\varphi_i) (p)}\mathbb{R}^n\right)$\\ [4pt]\par}
	
	we have that:
	
	{\centering\begin{tabular}{l}
		$\df f_p = (\df b_1, \ldots, \df b_\ell, \df (b_1 \varphi_{p_1})_p, \ldots, \df (b_{i-1} \varphi_{p_{i-1}})_p, \df (\varphi_i)_p, \df (b_{i+1} \varphi_{p_{i+1}})_p, \ldots, (b_\ell \varphi_{p_\ell})_p)$.
	\end{tabular}\retTwo\par}

	Yet $\df (\varphi_i)_p : T_p M \to T_{\varphi_i(p)}\mathbb{R}^n$ is a linear bijection (and thus has rank $n = \dim(M)$). It then follows that $\df (f)_p$ must also have rank at least $n = \dim(M)$. So, $\df f_p$ is full rank and thus injective. And since $p$ was arbitrary, we've finished proving that $f$ is an immersion. $\blacksquare$\retTwo
\end{myIndent}
